# 现金流量表附表间接法逐项取数规则（确认稿）

## 一、文档用途和范围

本文记录已经逐项确认的中国企业会计准则现金流量表补充资料第一部分，即“将净利润调节为经营活动现金流量”的取数规则。

本文不是现金流量表主表编制规则，也暂不处理补充资料中的“不涉及现金收支的重大投资和筹资活动”和“现金及现金等价物净变动情况”。后续制作 Agent Skill 时，应以本文作为业务口径依据，再将确定性取数、AI 判断、重要性水平控制和人工复核分别落实。

主要规范依据见`..\准则原文\企业会计准则第31号——现金流量表.md`和`..\知识库\知识库_现金流量表相关内容汇编.md`，重点为：

- 《企业会计准则第31号——现金流量表》；
- 《企业会计准则应用指南汇编2024》第三十二章“现金流量表”；
- 一般企业现金流量表及补充资料格式。

本文还包含本项目经逐项讨论后确定的实务规则。凡与规范原文相比增加了数据不足时的兜底方法、重要性水平控制或内部白名单，均属于本项目的执行规则，不冒充规范原文。

## 二、总公式

```text
经营活动产生的现金流量净额
＝净利润
＋资产减值准备
＋信用减值准备
＋折旧、折耗
＋无形资产摊销
＋长期待摊费用摊销
＋长期资产处置损失
＋固定资产报废损失
＋公允价值变动损失
＋不属于经营活动的财务费用
＋投资损失
＋递延所得税资产减少
＋递延所得税负债增加
＋存货减少
＋经营性应收项目减少
＋经营性应付项目增加
＋其他明确调整
```

上式中的“损失”“减少”“增加”等均为报表项目名称，实际金额可以为正数或负数：

- 费用、损失、资产减少、负债增加通常以正数填列；
- 收益、利得、资产增加、负债减少通常以负数填列；
- 最终必须满足“净利润＋全部调节项目＝主表经营活动产生的现金流量净额”。

## 三、统一取数和复核原则

### 3.1 数据来源分级

每个项目必须同时支持精确法和兜底法，不能假定企业一定能够提供完整序时账。

#### A级：序时账和凭证明细齐全

优先读取序时账、凭证分录、辅助核算、资产卡片和明细表，按业务事件和对方科目逐笔判断。这是精确取数方法。

#### B级：只有科目余额表或序时账不够明细

使用科目余额表的期初余额、本期借方发生额、本期贷方发生额和期末余额取数；再结合财务报表附注、资产变动表、科目名称和已知业务作必要拆分。

只要科目余额表能够区分专用明细科目，就应继续计算，不能因为没有凭证而直接停工。

#### C级：只有财务报表及附注

使用报表项目期初、期末余额和利润表发生额估算。涉及减值准备时，应将报表净值还原为原值；能够从附注识别的合并、处置、重分类和非现金交易应当调整，未发现证据的非经营性变动暂按零处理。

C级结果必须标明“报表兜底估算”，不能伪装成逐笔精确结果。

### 3.2 科目余额与发生额的区别

以下项目原则上使用本期发生额，不得用期末余额减期初余额代替：

- 资产减值准备；
- 信用减值准备；
- 各类折旧、折耗；
- 无形资产摊销；
- 长期待摊费用摊销；
- 长期资产处置损益；
- 固定资产报废损益；
- 公允价值变动损益；
- 不属于经营活动的财务费用；
- 投资损益。

以下项目以期初、期末余额变动为基础：

- 递延所得税资产；
- 递延所得税负债；
- 存货；
- 经营性应收项目；
- 经营性应付项目。

### 3.3 原值与净值

存货和经营性应收项目必须优先使用扣除减值准备前的原值。资产负债表列示的存货、应收账款等通常为净值，不能直接当作原值使用，否则会与“资产减值准备”或“信用减值准备”重复调整。

### 3.4 人工审核阈值

实际执行重要性水平是每次运行的必填参数，并应绑定企业或合并范围、会计期间、本位币。

```text
规则能够唯一判断
→ 系统自动处理，金额再大也不要求人工判断

规则不能唯一判断
→ 计算可能错分金额

可能错分金额＜实际执行重要性水平
→ AI结合现有资料作最可能判断并直接落数

可能错分金额≥实际执行重要性水平，且存在能够改变项目归属或金额的强冲突证据
→ 提交人工审核
```

人工升级必须同时满足金额门槛和强冲突证据两个条件，与《16个调节项目处理规则_复核确认稿》第6.3条、SKILL.md 和代码实现一致。

为防止大量小额事项拆分后规避人工审核，应同时检查：

- 单笔不确定金额；
- 同一科目、同一业务性质的不确定金额绝对值合计；
- 同一附表调节项目的不确定金额绝对值合计。

汇总时不得先让正负金额相互抵销。AI自行处理的小额事项仍应保存凭证或科目、金额、业务性质、归入项目和判断依据。

如果用户没有提供实际执行重要性水平，Skill不得自行编造金额。

### 3.5 合并报表

编制合并现金流量表补充资料时，除汇总各公司账套外，还必须纳入影响合并净利润和相关资产负债项目的合并调整分录。企业合并带入、处置子公司带出、内部交易抵销和外币报表折算不能混入本期正常经营变动。

### 3.6 防止重复调整

每笔业务只能进入一个调节项目。特别注意：

- 资产减值与信用减值不得重复；
- 折旧、摊销与存货原值变动应配套；
- 长期资产处置损益、固定资产报废损益、投资损益、公允价值变动损益不得交叉；
- 财务费用中的投资、筹资项目不得再进入投资损益；
- “其他明确调整”不得承接已经由前述项目处理的金额；
- 经营性应收、应付中的非经营性变动应与相应投资、筹资项目衔接。

## 四、逐项取数规则

### 4.1 净利润

#### 取数口径

取利润表本期净利润。合并报表取合并利润表的净利润总额，不仅取归属于母公司股东的净利润。

#### 精确法

直接读取最终利润表的“净利润”项目，并与损益类科目结转后的本年利润勾稽。

#### 科目余额表兜底

根据收入、费用、利得、损失和所得税费用的本期发生额计算税后净利润。不得用税前利润作为起点。

#### 校验

净利润必须与所使用财务报表的利润表一致；合并附表必须使用合并口径净利润。

### 4.2 资产减值准备

#### 计算公式

```text
资产减值准备调节额
＝本期计入损益的资产减值准备计提额
－本期计入损益的资产减值准备转回额
```

#### 纳入范围

包括存货跌价准备、投资性房地产减值准备、长期股权投资减值准备、固定资产减值准备、在建工程减值准备、工程物资减值准备、生物性资产减值准备、无形资产减值准备、商誉减值准备、合同资产减值准备、使用权资产减值准备等。

信用减值准备不在本项反映。

#### 精确法

从“资产减值损失”及已映射的相关损益科目取本期借方发生额减贷方发生额，排除损益结转凭证。科目混有信用减值时，根据对方准备科目和资产类别拆分。

#### 科目余额表兜底

专用“资产减值损失”科目核算清楚时：

```text
本项金额＝本期借方发生额－本期贷方发生额
```

只有利润表时，可使用利润表“资产减值损失”项目，但应确认其中没有混入信用减值。

#### 排除项目

- 使用准备核销或转销资产；
- 处置资产带走减值准备；
- 企业合并带入或处置子公司带出；
- 外币折算；
- 科目重分类；
- 期初调整；
- 未经过当期损益的其他准备变动。

#### 勾稽

```text
期末准备
＝期初准备
＋本期计提
－本期转回
－本期转销或核销
±合并、处置、折算、重分类等其他变动
```

准备变动表用于验证；附表本项只取“本期计提－本期转回”。

### 4.3 信用减值准备

#### 计算公式

```text
信用减值准备调节额
＝本期计入损益的信用减值准备计提额
－本期计入损益的信用减值准备转回额
```

#### 纳入范围

包括坏账准备、债权投资减值准备、贷款损失准备、租赁应收款减值准备等按照金融工具准则计入信用减值损失的项目。

本项目规则中，合同资产减值统一归入“资产减值准备”，不得重复。

#### 精确法

读取“信用减值损失”及相关损益科目的凭证明细：

- 借方计提为正数；
- 贷方转回为负数；
- 排除损益结转；
- 混合科目根据准备科目、金融资产类别和业务性质拆分。

收回已经核销的款项属于真实现金流入，不能把相关贷方发生额机械视为非现金转回。

#### 科目余额表兜底

信用减值损失科目核算清楚时：

```text
本项金额＝本期借方发生额－本期贷方发生额
```

若科目混有核销收回、重分类等事项，则结合准备科目余额变动表和报表附注分析；低于实际执行重要性水平的模糊金额由AI判断，达到阈值的提交人工。

#### 排除项目

- 使用准备核销应收款项；
- 企业合并带入或处置子公司带出；
- 外币折算；
- 准备科目之间的重分类；
- 前期差错和期初调整；
- 不经过当期损益的其他变动；
- 收回已核销款项形成的实际现金流入。

#### 勾稽

```text
期末准备
＝期初准备
＋本期计提
－本期转回
－本期核销
±合并、折算、重分类等其他变动
```

### 4.4 折旧、折耗

#### 计算公式

```text
折旧、折耗调节额
＝应纳入的本期正常计提发生额
－本期真正冲回或更正额
```

应纳入的账户包括：

- 固定资产累计折旧；
- 使用权资产累计折旧；
- 成本模式投资性房地产累计折旧；
- 油气资产累计折耗；
- 生产性生物资产累计折旧。

成本模式投资性房地产折旧与固定资产累计折旧使用完全相同的规则，不另设“其他”项目。公允价值模式投资性房地产不计提折旧，其公允价值变动进入“公允价值变动损失”。

#### 根据借方去向判断

| 借方去向 | 处理 |
|---|---|
| 管理费用、销售费用等期间费用 | 纳入 |
| 费用化研发支出 | 纳入 |
| 制造费用、生产成本、存货成本 | 纳入，与存货原值变动配套抵销 |
| 在建工程 | 剔除 |
| 资本化开发支出 | 剔除 |
| 其他非经营性长期资产成本 | 剔除 |

制造费用中的折旧即使尚未影响净利润，也必须纳入，因为它增加了存货原值；附表中“折旧加回”和“存货增加扣除”合计影响为零。

资本化进入在建工程等非经营性长期资产的折旧既未影响净利润，也未进入经营性存货，因此不纳入。

#### 精确法

从上述累计折旧、累计折耗科目的本期正常贷方发生额取数，逐笔查看借方去向；真正冲回或更正本期计提的借方发生额才冲减本项。

#### 科目余额表兜底

以已映射累计折旧、累计折耗科目的本期贷方发生额为起点，扣除能够从借方发生额、固定资产附注或资产变动表识别的处置转销、重分类和资本化金额。

资料不足但没有发现重大异常时，可以使用本期正常计提总额估算并降低证据等级。

#### 排除项目

- 处置资产时转销累计折旧；
- 企业合并带入或处置子公司带出；
- 资产类别转换和重分类；
- 外币折算；
- 期初数据迁移；
- 资本化进入非经营性长期资产的部分。

不得使用“期末累计折旧－期初累计折旧”直接取数。

### 4.5 无形资产摊销

#### 计算公式

```text
无形资产摊销调节额
＝应纳入的本期正常计提发生额
－本期真正冲回或更正额
```

成本模式投资性房地产中的土地使用权摊销归入本项；房屋建筑物折旧归入上一项。两者不得重复。

#### 根据借方去向判断

| 借方去向 | 处理 |
|---|---|
| 管理费用、销售费用等期间费用 | 纳入 |
| 费用化研发支出 | 纳入 |
| 制造费用、生产成本、存货成本 | 纳入 |
| 经营性合同成本等经营性资产 | 其变动纳入经营性项目时，本项纳入 |
| 在建工程 | 剔除 |
| 资本化开发支出 | 剔除 |
| 其他非经营性长期资产成本 | 剔除 |

#### 精确法

读取累计摊销科目的本期正常贷方发生额；企业采用直接冲减无形资产原值的方法时，读取无形资产科目的正常摊销贷方发生额，并分析借方去向。

#### 科目余额表兜底

使用累计摊销或无形资产摊销专用明细科目的本期贷方发生额，结合无形资产附注中的“本期计提摊销”复核。若无法识别资本化去向，按重要性水平规则由AI或人工判断。

#### 排除项目

- 处置无形资产时转销累计摊销；
- 企业合并、重分类、外币折算和期初迁移；
- 前期差错调整；
- 无形资产减值准备；
- 长期待摊费用摊销；
- 资本化进入非经营性长期资产的部分。

### 4.6 长期待摊费用摊销

#### 计算公式

```text
长期待摊费用摊销调节额
＝长期待摊费用本期贷方减少中应纳入的金额
－本期真正冲回或更正额
```

长期待摊费用通常没有单独的累计摊销备抵科目，因此应从长期待摊费用资产科目的本期贷方发生额出发，查看借方去向。

#### 根据借方去向判断

| 借方去向 | 处理 |
|---|---|
| 管理费用、销售费用、研发费用、营业外支出等成本费用类损益 | 纳入 |
| 制造费用、生产成本、存货 | 纳入，与存货原值变动配套 |
| 在建工程 | 剔除 |
| 资本化开发支出 | 剔除 |
| 其他非经营性长期资产 | 剔除 |
| 其他资产科目之间的重分类或余额转移 | 剔除 |

项目终止形成的一次性核销不根据“正常摊销”或“异常核销”的名称判断。只要借方进入成本费用类损益，就记入本项目；借方形成非经营性长期资产的，不记入。

#### 精确法

读取已映射长期待摊费用科目的本期贷方发生额，逐笔查看借方科目，保留进入成本费用类损益或存货成本的金额。

#### 科目余额表兜底

使用长期待摊费用科目的本期贷方发生额，结合附注明细中的“本期摊销”和“其他减少”拆分。没有明细时，专用科目贷方发生额可作为估算值；发现重大新增、处置、重分类或结算事项时按重要性水平升级处理。

#### 排除项目

- 转入其他资产；
- 企业合并带入或处置子公司带出；
- 外币折算和期初迁移；
- 前期差错调整；
- 与其他单位结算收回的款项；
- 未进入当期损益或经营性存货的减少。

不得直接使用“期初余额－期末余额”，因为其中还包含本期新增和其他变动。

### 4.7 长期资产处置损失（收益以负数填列）

#### 计算公式

```text
长期资产处置调节额
＝处置损失
－处置收益
```

本项取处置长期资产影响净利润的净损益，不取收到或支付的现金。

#### 纳入范围

- 正常出售、转让固定资产；
- 无形资产；
- 在建工程及其他长期资产；
- 使用权资产处置或租赁终止形成的处置损益；
- 生产性生物资产；
- 非货币性资产交换产生并计入当期损益的长期资产处置损益；
- 真正的投资性房地产处置损益。

#### 普通长期资产取数

```text
本项金额
＝相关资产处置损益借方发生额
－相关资产处置损益贷方发生额
```

应结合处置凭证和资产卡片确认业务性质。不得把处置价款、资产原值、累计折旧、累计摊销、减值准备和销项税额分别重复计入。

#### 投资性房地产

投资性房地产处置常通过“其他业务收入”和“其他业务成本”核算，因此不能只抓“资产处置损益”科目。

```text
投资性房地产处置调节额
＝处置对应的其他业务成本
＋计入损益的处置费用
－处置对应的其他业务收入
```

一般企业处置真正的投资性房地产，主表原则上应列入投资活动，附表相应加回处置损失或扣除处置收益。Skill必须核对主表是否误分为经营活动。

如果房地产在处置前已经按准则转为存货并作为正常商品销售，则主表列入经营活动，本项目不调整，相关成本通过“存货减少”等项目处理。

非货币性处置不产生主表现金流，但只要处置损益影响净利润，仍应在本项剔除。

#### 科目余额表兜底

使用“资产处置损益”明细科目的本期借方减贷方发生额；投资性房地产另取明确属于处置业务的其他业务收入和其他业务成本。科目无法区分租金业务和处置业务时，结合报表附注和资产减少额判断，并适用重要性水平规则。

#### 排除项目

- 固定资产盘亏、报废和毁损损益；
- 长期股权投资、子公司和金融资产处置损益；
- 存货和消耗性生物资产的正常销售损益；
- 公允价值变动损益；
- 资产减值计提和转回；
- 已归入长期待摊费用摊销的一次性核销。

#### 主表核对

处置固定资产、无形资产、真正的投资性房地产和其他长期资产形成的现金净额，应核对是否列入投资活动。主表分类错误时，不能仅修改附表迁就错误分类。

### 4.8 固定资产报废损失（收益以负数填列）

#### 计算公式

```text
固定资产报废调节额
＝营业外支出中的固定资产报废、毁损、盘亏净损失
－营业外收入中的相关净收益
```

#### 精确法

按报废凭证和固定资产卡片识别。正常出售、转让归入上一项，不能重复。

#### 科目余额表兜底

从营业外支出、营业外收入中明确标注固定资产报废、毁损、盘亏的明细科目取数。混合科目应结合固定资产附注的本期报废减少额分析。

#### 勾稽

```text
净损失
＝报废资产账面价值
＋清理费用
－残料收入
－保险赔偿等相关收入
```

报废清理产生的现金净额应核对主表投资活动；附表损失加回、收益扣除。

### 4.9 公允价值变动损失（收益以负数填列）

#### 计算公式

```text
公允价值变动调节额
＝公允价值变动损益借方发生额
－公允价值变动损益贷方发生额
```

#### 纳入范围

包括交易性金融资产、交易性金融负债、衍生工具和公允价值模式投资性房地产等本期重新计量且计入当期损益的金额。

#### 精确法

读取公允价值变动损益凭证明细，按标的资产或负债确认属于本期非现金重新计量。

#### 科目余额表兜底

公允价值变动损益科目核算清楚时，使用本期借方发生额减贷方发生额，并与利润表“公允价值变动收益”项目勾稽。

#### 排除项目

- 计入其他综合收益的公允价值变动；
- 损益结转；
- 处置时的科目重分类；
- 已经实际发生现金结算的金额；
- 已归入长期资产处置损益或投资损益的金额。

### 4.10 不属于经营活动的财务费用

#### 计算公式

```text
调节额
＝本期计入损益且对应投资、筹资活动的财务费用
－本期计入损益且对应投资、筹资活动的财务收益
```

判断依据是资金来源和业务性质，不是“财务费用”科目名称。

#### 纳入范围

- 借款、债券、租赁负债等融资利息费用：加回；
- 因借贷发生并计入当期损益的担保费、承诺费、融资服务费：加回；
- 未确认融资费用等融资性摊销：加回；
- 理财产品、债权投资等产生但实务中记入利息收入的投资收益：扣除。

#### 不纳入范围

- 普通银行活期、结算账户存款产生的利息收入：属于经营活动，不调整；
- 银行结算手续费、经营性现金折扣等经营活动费用；
- 已资本化进入在建工程等资产成本、未影响净利润的借款费用；
- 金融企业作为日常经营业务的利息收支。

#### 汇兑损益

汇兑损益不得整科目取数：

- 经营性应收、应付结算产生的汇兑损益不在本项调整；
- 与借款等融资项目有关的汇兑损益，按对应现金流性质分析；
- 与现金及现金等价物汇率变动有关的金额，还应与主表“汇率变动对现金及现金等价物的影响”核对；
- 不得与经营性应收、应付变动重复。

#### 精确法

读取财务费用明细和对应金融工具，区分普通存款、投资产品、借款、债券、租赁负债和经营性结算项目。

#### 科目余额表兜底

使用已经按业务性质设置的财务费用明细科目本期发生额。混合科目无法拆分时，优先参考借款附注、利息费用附注、理财及债权投资收益；其余模糊金额适用重要性水平规则。

本项取影响净利润的权责发生制金额，不等于主表本期实际支付或收到的现金。

### 4.11 投资损失（收益以负数填列）

#### 计算公式

```text
投资损益调节额
＝属于投资活动的投资损失
－属于投资活动的投资收益
```

#### 一般企业纳入范围

- 权益法确认的投资损失或收益；
- 长期股权投资、金融资产处置损益；
- 债权投资、理财产品产生的投资收益；
- 处置子公司或其他营业单位产生的投资损益。

取本期影响净利润的应计金额，不取实际收到的投资现金。

#### 精确法

读取投资收益及相关损失科目的明细，按投资标的和业务事件分类。

#### 科目余额表兜底

一般企业投资收益科目核算清楚时，可使用利润表“投资收益”或科目余额表本期发生额，收益以负数填列。存在混合业务时，结合投资和处置附注拆分。

#### 排除项目

- 已归入公允价值变动损益的金额；
- 已归入长期资产处置损益的金额；
- 金融企业属于日常经营活动的投资交易；
- 经营性应收票据贴现；
- 按业务实质属于经营活动且已由其他项目处理的贸易债权债务事项。

### 4.12 递延所得税资产减少（增加以负数填列）

#### 基础公式

没有需要剔除的项目时：

```text
递延所得税资产调节额
＝期初递延所得税资产余额
－期末递延所得税资产余额
```

存在剔除项时：

```text
调节额
＝期初余额－期末余额
±剔除未影响当期净利润的资产变动
```

递延所得税资产减少为正数，增加为负数。

#### 精确法

读取递延所得税资产明细，只保留对方科目为当期所得税费用、确实影响本期净利润的变动。

#### 科目余额表兜底

没有发现下列剔除项时，直接使用“期初－期末”。只有报表净列示金额时，应先还原递延所得税资产与负债的列报抵销影响。

#### 剔除项目

- 计入其他综合收益或所有者权益的变动；
- 企业合并带入或处置子公司带出；
- 外币折算；
- 重分类；
- 期初调整和前期差错；
- 递延所得税资产与负债列报抵销口径的变化。

### 4.13 递延所得税负债增加（减少以负数填列）

#### 基础公式

没有需要剔除的项目时：

```text
递延所得税负债调节额
＝期末递延所得税负债余额
－期初递延所得税负债余额
```

存在剔除项时：

```text
调节额
＝期末余额－期初余额
±剔除未影响当期净利润的负债变动
```

递延所得税负债增加为正数，减少为负数。

#### 精确法

读取递延所得税负债明细，只保留对方科目为当期所得税费用、确实影响本期净利润的变动。

#### 科目余额表兜底

没有发现计入其他综合收益或权益、企业合并、处置子公司、外币折算、重分类和期初调整等事项时，直接使用“期末－期初”。

#### 合并勾稽

```text
递延所得税资产减少
＋递延所得税负债增加
＝本期计入利润表的递延所得税费用
```

若不相等，应检查权益类确认、企业合并、折算、重分类和列报抵销等非损益变动。

### 4.14 存货减少（增加以负数填列）

#### 核心口径

存货必须使用扣除存货跌价准备前的原值，不能直接使用资产负债表列示的净值。

#### 计算公式

```text
存货调节额
＝期初存货原值
－期末存货原值
＋已识别的非经营性净增加
```

“非经营性净增加”使用带符号金额：

- 企业合并、非货币性交易、资产重分类等带入存货：正数；
- 存货转入在建工程、对外投资、处置子公司带出：负数；
- 使用存货跌价准备核销存货原值：负数；
- 资本化借款利息进入存货：正数，因为相关现金流属于筹资活动。

#### 不作剔除的项目

- 计入存货成本的折旧和摊销，因为要与前面的折旧、摊销加回配套抵销；
- 正常赊购存货，由经营性应付项目处理；
- 直接计入当期成本费用类损益的存货盘亏、毁损，因为存货原值减少会抵销该项非现金损失。

#### 精确法

汇总所有存货原值科目的期初、期末余额，并通过序时账识别非经营性带入、带出、转换、核销和资本化利息。

#### 科目余额表兜底

科目余额表能够取得存货原值时：

```text
期初存货原值－期末存货原值＋已识别的非经营性净增加
```

没有证据显示存在非经营性变动时，兜底暂按零处理。

#### 只有报表净值时的兜底

```text
存货调节额
＝期初存货净值
－期末存货净值
－本期存货减值计提减转回
＋已识别的非经营性净增加
```

若本期存在存货跌价准备核销、合并或其他准备变动，上式只能作为近似值，应结合附注明细补充调整。

### 4.15 经营性应收项目减少（增加以负数填列）

#### 计算公式

```text
经营性应收调节额
＝经营性应收项目期初原值
－经营性应收项目期末原值
＋已识别的非经营性净增加
```

#### 纳入范围

- 应收账款；
- 应收票据；
- 预付账款；
- 合同资产；
- 长期应收款中的经营性部分；
- 其他应收款中的经营性部分；
- 其他明确属于经营活动的应收项目。

全部使用扣除信用减值准备前的原值。

#### 剔除项目

- 投资、融资和长期资产处置形成的应收款；
- 企业合并、处置子公司和外币报表折算带入带出的变动；
- 背书购买长期资产、债转股、非货币性交易等未收现减少；
- 使用坏账准备核销的应收款原值；
- 其他没有形成经营现金流的余额变动。

直接计入成本费用类损益的坏账核销不剔除，因为应收原值减少需要抵销该项非现金损失。

#### 精确法

根据序时账和对方科目逐笔识别经营性与非经营性应收，计算各原值科目的“期初－期末”，再加入应剔除的非经营性净增加。

#### 科目余额表兜底

按已映射的经营性应收原值科目汇总“期初－期末”。混合科目根据现有明细、科目名称、报表附注和AI作大致划分；没有证据的非经营性变动暂按零处理。

#### 只有报表净值时的兜底

```text
经营性应收调节额
＝期初经营性应收净值
－期末经营性应收净值
－本期对应信用减值计提减转回
＋已识别的非经营性净增加
```

若存在坏账准备核销、合并或其他准备变动，上式为近似值。

### 4.16 经营性应付项目增加（减少以负数填列）

#### 计算公式

```text
经营性应付调节额
＝经营性应付项目期末余额
－经营性应付项目期初余额
－已识别的非经营性净增加
```

#### 纳入范围

- 应付账款、应付票据；
- 预收账款、合同负债；
- 应付职工薪酬；
- 应交税费；
- 其他应付款、长期应付款中的经营性部分；
- 其他明确属于经营活动的应付项目。

#### 剔除项目

- 购买固定资产、无形资产、投资性房地产等形成的应付款；
- 借款利息、担保费等筹资性应付款；
- 应付股利、借款和租赁负债；
- 企业合并、处置子公司和外币报表折算等变动；
- 资本化进入在建工程等长期资产的职工薪酬及其他应付款；
- 其他没有形成经营现金流的余额变动。

#### 精确法

根据序时账和对方科目逐笔判断经营性、投资性和筹资性应付，计算经营性部分“期末－期初”，再扣除非经营性净增加。

#### 科目余额表兜底

按已映射的经营性应付科目计算“期末－期初”。混合科目根据现有明细、科目名称、报表附注和AI作大致划分；没有证据的非经营性变动暂按零处理。

### 4.17 其他明确调整

#### 默认规则

“其他”不得用于承接无法解释的差额。除内部白名单事项外，本项目原则上填零。

#### 已确认内部白名单

本项目经用户确认采用以下三项白名单：

1. 权益结算的股份支付费用；
2. 递延收益、政府补助的非现金摊销；
3. 未归入前述项目的债务重组损益。

这三项是本项目确认的 Skill 内部白名单，不表述为财政部规范性文件对“其他”项目的明文正列举。

#### 计算规则

```text
其他明确调整
＝白名单内、未被前述项目覆盖的非现金费用或损失
－白名单内、未被前述项目覆盖的非现金收益或利得
```

每笔金额必须同时满足：

- 确实影响本期净利润；
- 没有形成经营活动现金流；
- 属于上述三项白名单；
- 没有在前述调节项目中重复反映；
- 有科目、凭证、附注或其他明确账务证据。

#### 精确法

按股份支付、递延收益、政府补助和债务重组事件逐笔识别，记录金额、正负方向及未重复调整的依据。

#### 科目余额表兜底

只有专用明细科目或报表附注明确列示时才取数。无法识别具体白名单事项时，本项目填零。

## 五、经营性应收、应付无法解释差额的处理规则

经营性应收、应付中的非经营性净增加或减少往往难以完整识别。按本项目已经确认的执行规则：

1. 先用现有序时账、科目余额表和附注，尽可能计算经营性应收、应付的合理金额；
2. 模糊事项先适用实际执行重要性水平规则：低于阈值由AI判断，达到阈值提交人工；
3. 全部已知项目处理后，计算补充资料与主表经营活动现金流量净额的剩余差额；
4. **最终仍无法解释的差额不得倒轧。** 不得把差额随机或按比例分配到经营性应收、经营性应付或任何其他项目，也不得放入“其他明确调整”；必须回到来源凭证、余额桥接和金额归属查明差异来源。核对未通过时只交付诊断结果，不称为正式完成。

> 说明：本节早期版本曾允许在“经营性应收项目减少”和“经营性应付项目增加”之间按随机比例倒轧。该口径与《16个调节项目处理规则_复核确认稿》第16.4条“不按随机比例分配到经营性应收、应付或其他项目”冲突，现予废止，以复核确认稿为准。

## 六、最终勾稽和输出要求

### 6.1 必须通过的勾稽

```text
净利润＋全部调节项目
＝补充资料经营活动产生的现金流量净额
＝主表经营活动产生的现金流量净额
```

还应检查：

- 递延所得税资产减少＋递延所得税负债增加＝本期计入利润表的递延所得税费用；
- 折旧、摊销计入存货的金额与存货原值变动配套；
- 资产减值、信用减值与相应准备变动表勾稽；
- 长期资产处置、固定资产报废的现金流分类与主表投资活动一致；
- 投资损益、财务费用与主表投资、筹资活动分类一致；
- “其他明确调整”只有三项白名单内容；
- 最终差额没有进入“其他明确调整”。

### 6.2 每个项目的输出留痕

每个项目至少输出：

- 项目名称；
- 最终金额；
- 使用的数据等级：A级、B级或C级；
- 取数科目或报表项目；
- 计算公式；
- 纳入金额；
- 剔除金额及原因；
- AI判断事项及依据；
- 达到实际执行重要性水平的人工审核事项；
- 与其他项目防止重复的说明。

经营性应收、应付另行输出：

- 初算金额；
- 已识别的非经营性净增加修正；
- 修正后金额；
- 与主表经营活动现金流量净额的剩余差额及差异来源分析；
- 最终勾稽结果。

剩余差额只报告和分析，不得在经营性应收、应付之间分配倒轧。

### 6.3 禁止事项

- 不得把资产负债表净值当作存货或经营性应收原值；
- 不得用减值准备、累计折旧或累计摊销的余额差代替本期正常发生额；
- 不得把损益科目名称直接等同于现金流分类；
- 不得把全部财务费用机械加回；
- 不得把普通银行结算存款利息收入默认列为投资活动；
- 不得遗漏成本模式投资性房地产折旧和土地使用权摊销；
- 不得把真正的投资性房地产处置现金默认列为经营活动；
- 不得把“其他明确调整”作为差额蓄水池；
- 不得因为没有序时账就停止计算；
- 不得在规则能够唯一判断时增加不必要的人工审核。

## 七、后续制作 Agent Skill 时的结构要求

后续 Skill 建议分为三层：

- `SKILL.md`：工作流程、资料分级、实际执行重要性水平规则、取数顺序、人工升级条件和最终勾稽；
- `references`：保存本文逐项业务口径、规范依据、科目范围、纳入及排除规则；
- `scripts`：执行确定性的科目汇总、发生额计算、余额还原、绝对值聚合、阈值比较和勾稽检查。

Agent只处理确定规则无法覆盖的会计判断；能够由公式和明确科目映射完成的事项应由确定性程序计算。
