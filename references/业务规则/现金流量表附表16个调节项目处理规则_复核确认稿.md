- 补充资料调整的是净利润中的非现金影响，以及虽影响净利润但现金属于投资或筹资活动的事项。
- 信用减值损失、资产减值损失、资产处置损益、公允价值变动损益在利润表中分别列报，Skill必须保持项目边界。
- 非流动资产正常处置与毁损报废不是同一事项，应分别处理。
- 使用权资产计提折旧，租赁负债利息通常属于筹资相关财务费用。
- 实际收到的政府补助，无论与资产相关还是与收益相关，均在“收到其他与经营活动有关的现金”列报。
- 其他综合收益、直接计入权益、企业合并和外币报表折算等未进入当期净利润的金额，不得机械纳入附表调节。

## 三、统一处理架构

### 3.1 正式输入来源

1. 净利润由客户输入，或者从已核对的财务报表取得。
2. 其余16项必须以完整序时账和完整科目余额表为输入。
3. 客户原始序时账必须先经过现有“序时账分析器”，生成包含对方一级科目、匹配类型和原始行追踪信息的标准序时账。
4. 科目余额表中的一级、二级、末级科目是一套科目层级；客户、供应商、部门、项目等辅助项目是与科目层级平行的维度。辅助项目不得与所属科目重复汇总。

### 3.2 内部数据处理

1. Excel仅用于输入和输出。
2. 数据读取后立即标准化为内部表结构，结构化计算优先使用Pandas和Parquet。
3. 规则命中、金额占用、AI判断、余额核对和异常信息使用JSONL留痕。
4. 内部所有金额必须保留来源文件、工作表、原始行、凭证标识、科目、辅助项目和拆分依据，能够追溯到原始Excel。

### 3.3 数据来源优先级

1. 序时账负责候选筛选、业务事件识别和精确金额计算。
2. 科目余额表本期借贷发生额主要用于校验序时账完整性，不是第二套重复取数来源。
3. 科目余额表期初、期末余额主要用于递延所得税、存货、经营性应收和经营性应付。
4. 只有序时账无法精确分类、余额表又存在明确专用明细科目时，才允许降级使用余额表发生额，并必须标注精度损失。

### 3.4 金额与符号

1. 费用、损失及应加回金额使用正数。
2. 收益、利得及应扣除金额使用负数。
3. 损益项目一般按符合条件的借方发生额减贷方发生额计算。
4. 资产负债表项目按本文件规定的期初、期末方向和非现金修正计算。
5. 取数单位是“金额片段”，不是整张凭证。一张凭证可以进入多个项目，但同一金额片段只能占用一次。

### 3.5 损益结转排除

仅排除满足以下组合证据的具体损益科目行，不删除整张凭证：

1. 本行末级科目属于损益类；
2. 对方一级科目是本年利润或已确认的损益结转中间科目；
3. 借贷方向符合损益结转；
4. 匹配类型、摘要等辅助证据不与结转判断冲突。

利润分配、应付股利等业务分录即使使用了“结转损益规则”匹配类型，也不得仅凭匹配类型删除。

### 3.6 判断证据顺序

1. 明确的会计科目和准则适用范围；
2. 完整凭证及金额对应关系；
3. 资产、债权债务或交易事件的经济实质；
4. 对方一级科目；
5. 辅助核算；
6. 摘要；
7. 科目余额表和报表勾稽。

摘要不得推翻明确的会计分录和业务实质。

## 四、16个调节项目确认规则

## 1. 资产减值准备

### 候选范围

同时从损益科目和准备科目双向筛选，至少显式覆盖：

- 存货跌价准备；
- 合同资产减值准备；
- 长期股权投资减值准备；
- 投资性房地产减值准备；
- 固定资产减值准备；
- 在建工程减值准备；
- 工程物资减值准备；
- 使用权资产减值准备；
- 无形资产减值准备；
- 商誉减值准备；
- 油气资产减值准备；
- 生产性生物资产减值准备；
- 持有待售资产减值准备；
- 其他适用非信用减值模型的长期资产减值准备。

### 纳入

1. 借记资产减值损失、贷记减值准备的计提；
2. 允许转回并贷记资产减值损失的转回，作为负数；
3. 未通过准备科目、直接减少资产账面价值并计入资产减值损失的金额。

### 排除

1. 信用减值；
2. 使用准备核销或转销资产原值；
3. 处置资产带走的准备；
4. 企业合并、处置子公司、外币折算、重分类和期初调整；
5. 未进入当期损益的准备变动；
6. 损益结转。

### 特殊校验

- 存货和合同资产等按适用准则允许转回的项目，可以按实际损益确认转回。
- 固定资产、无形资产、商誉、长期股权投资等适用《企业会计准则第8号》的长期资产减值通常不得转回。发现转回分录时，应输出会计异常提示。
- 如果异常转回在期末仍实际影响净利润，现金流量表仍应按其实际损益影响作负数调整；异常提示不能替代现金流量调整。

### 公式

`资产减值准备＝影响当期损益的计提＋直接减值－影响当期损益的转回`

## 2. 信用减值准备

### 候选范围

覆盖应收账款、应收票据、其他应收款、贷款、债权投资、其他债权投资、租赁应收款、合同资产以外的预期信用损失准备，以及财务担保合同和贷款承诺等实际计入信用减值损失的项目。

合同资产减值按照本项目既定列报口径归入第1项，不再进入第2项。

### 纳入

1. 影响当期损益的信用减值计提；
2. 影响当期损益的信用减值转回，作为负数；
3. 未使用准备、直接计入信用减值损失的坏账损失。

### 排除

1. 使用坏账准备核销应收原值；
2. 收回以前已核销款项形成的真实现金流入；
3. 企业合并、处置子公司、外币折算、重分类和期初调整；
4. 计入其他综合收益但未进入净利润的金额；
5. 损益结转。

### 公式

`信用减值准备＝影响当期损益的信用减值计提＋直接信用损失－影响当期损益的转回`

所有应收原值核销，无论是否经过准备科目，只要对应损失已经在本项调整，均必须在第14项剔除，防止重复。

## 3. 折旧、折耗

### 覆盖范围

- 固定资产折旧；
- 使用权资产折旧；
- 成本模式投资性房地产中建筑物折旧；
- 生产性生物资产折旧；
- 探明矿区权益折耗；
- 油气井及相关设施折耗；
- 油气辅助设备按固定资产规则计提的折旧。

### 纳入

1. 计入管理费用、销售费用、研发费用等当期损益的折旧、折耗；
2. 计入制造费用、生产成本和存货成本的折旧、折耗；
3. 进入其他经营性资产成本，且该资产余额变动在经营性项目中处理的金额。

### 排除

1. 进入在建工程；
2. 进入资本化开发支出；
3. 进入其他非经营性长期资产；
4. 处置转销累计折旧、折耗；
5. 企业合并、处置子公司、资产重分类、外币折算和期初迁移。

### 异常状态

公允价值模式投资性房地产、持有待售资产、已提足折旧仍继续使用的资产和单独计价土地等出现不应计提的折旧时，应提示会计异常。若该金额实际保留在当期损益或经营性资产成本中，仍按实际影响调整。

### 公式

`折旧、折耗＝符合条件的正常贷方计提－本期真实冲回或更正`

精确取数使用当期计提发生额，不使用累计折旧或累计折耗期末减期初。

## 4. 无形资产摊销

### 纳入

1. 使用寿命有限、已经达到预定用途的无形资产当期摊销；
2. 成本模式投资性房地产中土地使用权摊销；
3. 计入当期损益或经营性存货、经营性合同成本的摊销；
4. 符合无形资产确认条件的数据资源摊销。

### 排除

1. 使用寿命不确定的无形资产；
2. 尚未达到预定用途的无形资产；
3. 持有待售期间按准则停止摊销的资产；
4. 进入在建工程、资本化开发支出或其他非经营性长期资产的摊销；
5. 处置转销、减值、合并、重分类、折算和前期差错。

前三类资产原则上不应摊销。若错误摊销已经进入客户确认的本期净利润或经营性资产成本，仍按实际非现金影响纳入本项，并同时提示会计差错；若客户先完成更正并重新确认净利润，则按更正后的数据重跑，不再保留该错误金额。

无形资产预期不能带来经济利益而一次性转销的账面价值，不属于日常摊销，转入第6项。

### 公式

`无形资产摊销＝实际进入净利润或经营性资产成本的当期摊销－本期真实冲回或更正`

## 5. 长期待摊费用摊销

### 纳入

1. 计入当期损益的正常摊销；
2. 计入制造费用、生产成本、存货等经营性资产成本的摊销；
3. 已不能带来未来经济利益而一次性计入损益的剩余账面价值，单独标记为“一次性转销”；
4. 符合长期待摊费用核算条件的租入资产改良支出摊销。

### 排除

1. 转入其他资产；
2. 进入在建工程、资本化开发支出或其他非经营性长期资产；
3. 现金退款、现金结算或与其他单位结算收回；
4. 企业合并、处置子公司、外币折算、期初迁移和前期差错。

### 公式

`长期待摊费用摊销＝正常摊销＋一次性非现金转销－本期真实冲回或更正`

不使用长期待摊费用期初减期末直接取数。

## 6. 长期资产处置损失

### 纳入

1. 固定资产正常出售或转让；
2. 无形资产出售、终止确认或预期不能再带来经济利益的转销；
3. 在建工程及其他非金融长期资产处置；
4. 成本模式或公允价值模式投资性房地产的真正处置；
5. 使用权资产部分或全部终止产生的损益；
6. 生产性生物资产、油气资产处置；
7. 非货币性资产交换和债务重组中，按报表格式应列入资产处置损益的非金融长期资产处置损益。

### 排除

1. 固定资产毁损、报废和盘亏，转第7项；
2. 长期股权投资、金融资产和子公司处置，转第10项；
3. 消耗性生物资产和已转为存货的房地产正常销售；
4. 公允价值重新计量，转第8项；
5. 资产减值，转第1项。

### 计算原则

按处置事件最终计入损益的净额取数，不再把处置价款、资产原值、累计折旧、累计摊销、减值准备和税额分别相加。

使用权资产终止损益可以进入本项，但相关租赁现金流必须根据《企业会计准则第21号》单独判断，不能自动视为投资活动。

### 公式

`长期资产处置损失＝处置损失－处置收益`

## 7. 固定资产报废损失

### 纳入

1. 固定资产毁损；
2. 固定资产报废；
3. 固定资产盘亏，作为内部扩展子类型单独标记；
4. 与同一事件相关的清理费用、残料收入和保险赔偿形成的最终净损益。

### 排除

1. 固定资产正常出售和转让；
2. 存货盘亏或毁损；
3. 其他非流动资产处置；
4. 资产减值；
5. 已经进入第6项的相同处置损益。

同一报废事件允许跨凭证、跨资产卡片关联，不要求全部分录出现在同一张凭证。

### 公式

`固定资产报废损失＝相关营业外支出－相关营业外收入`

不同报废事件的利得和损失不得先行相互抵销后再失去事件追踪信息。

## 8. 公允价值变动损失

### 纳入

实际计入当期损益的纯公允价值重新计量，包括符合条件的金融资产、金融负债、衍生工具、公允价值模式投资性房地产、或有对价以及其他准则明确要求计入损益的公允价值变动。

### 排除

1. 计入其他综合收益的公允价值变动；
2. 企业自身信用风险计入其他综合收益的部分；
3. 现金流量套期有效部分；
4. 损益结转；
5. 已经按处置、投资损益或财务费用占用的相同金额。

### 结算与处置

不能再使用“已经发生现金结算就全部排除”的规则。应按事件拆分：

- 计量日纯重新计量损益归本项；
- 处置或结算形成的已实现投资损益归第10项；
- 进入财务费用的融资或投资相关损益归第9项；
- 属于企业核心经营业务的金额按经营活动处理；
- 每个金额片段只能进入一个项目。

### 公式

`公允价值变动损失＝公允价值变动损益借方发生额－贷方发生额`

## 9. 不属于经营活动的财务费用

### 纳入

1. 借款、债券和其他融资负债的费用化利息；
2. 租赁负债利息；
3. 融资性担保费、承诺费、服务费及实际利率法摊销；
4. 计入财务费用的投资产品或债权投资利息收入；
5. 投资活动或筹资活动相关的汇兑损益；
6. 现金及现金等价物自身产生并计入净利润的汇兑损益；
7. 不属于经营活动的预计负债折现摊销等融资成分。

### 排除

1. 普通结算账户存款利息和银行结算手续费；
2. 经营性现金折扣；
3. 经营性应收、应付的本位币汇兑损益；
4. 已资本化且未影响净利润的借款费用；
5. 金融企业作为核心经营业务的利息收支。

### 关键修正

原讨论稿排除“现金及现金等价物自身汇率变动”的规则错误，现予删除。

现金及现金等价物的汇兑损益应在本项从经营活动现金流量中抵销，并与主表“汇率变动对现金及现金等价物的影响”核对。当前版本输入协议尚未提供主表汇率影响金额，因此该项独立核对暂以诊断说明代替；取得主表汇率影响金额后应补充核对。

### 公式

`不属于经营活动的财务费用＝符合条件的费用及损失－符合条件的收益`

精确取数使用权责发生制损益金额，不使用当期实际支付利息倒推。

## 10. 投资损失

### 纳入

1. 权益法投资收益或损失；
2. 投资利息、股利等权责发生制投资收益；
3. 长期股权投资和金融资产处置损益；
4. 处置子公司或其他营业单位产生的投资损益；
5. 丧失控制权及剩余股权重新计量损益；
6. 其他按经济实质属于投资活动、且实际进入当期净利润的损益。

### 排除

1. 公允价值重新计量，转第8项；
2. 信用减值，转第2项；
3. 非金融长期资产处置，转第6项；
4. 贸易债权债务重组已经由经营性项目抵销的金额；
5. 经营性应收票据贴现或保理；
6. 已经进入第9项的投资利息；
7. 金融企业核心经营活动形成的投资交易。

### 公式

`投资损失＝符合条件的投资损失－符合条件的投资收益`

即使投资收益已经实际收到现金，由于相关现金在主表列入投资活动，进入净利润的投资收益仍应在附表完整扣除。

## 11. 递延所得税资产减少

### 精确法

按照当期递延所得税资产变动中实际计入所得税费用、从而影响净利润的金额计算，不要求分录必须把“所得税费用”作为唯一直接对方科目。

纳入税率变化、可收回性重新评估、以前未确认项目在本期确认以及其他实际计入所得税费用的变化。

### 排除

1. 计入其他综合收益或所有者权益；
2. 企业合并；
3. 外币财务报表折算；
4. 期初调整和前期差错；
5. 仅由重分类或列报抵销产生的变化。

### 公式

`递延所得税资产减少＝影响净利润的递延所得税资产贷方变动－借方变动`

余额表兜底公式为：

`期初递延所得税资产余额－期末递延所得税资产余额`

兜底使用同一纳税主体和税收管辖区列报抵销前的总额，并尽可能剔除不影响净利润的变化。

## 12. 递延所得税负债增加

### 精确法

按照当期递延所得税负债变动中实际计入所得税费用、从而影响净利润的金额计算。

### 排除

与第11项相同，排除权益、其他综合收益、企业合并、外币报表折算、期初调整、前期差错、重分类和列报抵销变化。

### 公式

`递延所得税负债增加＝影响净利润的递延所得税负债贷方变动－借方变动`

余额表兜底公式为：

`期末递延所得税负债余额－期初递延所得税负债余额`

第11项与第12项合计，应当能够解释当期净利润中递延所得税费用或收益的相应部分。

## 13. 存货减少

### 余额范围

使用存货原值，不扣除存货跌价准备。根据业务实质覆盖原材料、在产品、库存商品、周转材料、发出商品、委托加工物资、合同履约成本中的存货或经营性部分、消耗性生物资产、收获后的农产品以及房地产开发存货等。

### 基础公式

`存货减少＝期初经营性存货原值－期末经营性存货原值＋非经营性净增加修正`

### 需要修正

1. 企业合并、非货币性资产交换、债务重组、接受捐赠和资产重分类等非现金带入存货；
2. 存货转入长期资产、对外投资、处置子公司等非经营性带出；
3. 资本化借款费用进入存货；
4. 权益结算股份支付进入尚未出售存货；
5. 使用存货跌价准备核销存货原值；
6. 直接计入资产减值损失并已在第1项调整的存货原值减记。

### 核销防重复

- 使用存货跌价准备核销原值，或者直接减记原值且相关损失已经进入第1项时，必须从存货毛额减少中剔除。
- 普通盘亏、毁损若直接计入成本费用且没有进入第1项，则保留在存货减少中，由“损益减少＋存货减少”自然抵销。
- 计入存货成本的折旧和摊销不作非经营性修正，因为第3至第5项的加回与存货增加属于允许的配套抵销。

不得使用随机方法把无法解释的差额分配到存货、经营性应收或经营性应付。

## 14. 经营性应收项目减少

### 余额范围

使用扣除信用减值准备前的原值，并按业务实质覆盖：

- 应收账款和应收票据；
- 预付账款和合同资产；
- 税费返还和其他经营性应收；
- 员工备用金；
- 经营性保证金、押金；
- 长期应收款中的经营性部分。

科目名称不是唯一判断依据。投资、融资和长期资产处置形成的应收款必须排除。

### 基础公式

`经营性应收项目减少＝期初经营性应收原值－期末经营性应收原值＋非经营性净增加修正`

### 需要修正

1. 投资、融资或长期资产处置形成的应收增减；
2. 应收款背书购买长期资产；
3. 债转股、抵债、非货币性结算和债务重组；
4. 企业合并、处置子公司和境外经营报表折算；
5. 已由第2项处理的坏账核销；
6. 其他不伴随经营活动现金收付的原值变化。

### 关键修正

原讨论稿“直接计入损益的坏账核销不作修正”的例外删除。

只要坏账损失已经由第2项加回，相应应收原值减少就必须从第14项剔除，否则会重复增加经营活动现金流量。

### 外币和保理

- 经营性应收在本位币账簿中的汇兑变化一般保留，由汇兑损益和应收余额变动自然抵销。
- 境外经营财务报表折算差额不影响净利润，必须剔除。
- 应收账款保理、贴现和背书按风险报酬是否实质转移及现金流业务性质判断，不按凭证名称机械分类。
- 租赁预付款和租赁保证金原则上按租赁业务实质判断；属于使用权资产取得或租赁融资安排的，不进入普通经营性应收池，短期租赁和低价值资产租赁除外。

## 15. 经营性应付项目增加

### 余额范围

按业务实质覆盖：

- 应付账款和应付票据；
- 预收账款和合同负债；
- 应付职工薪酬；
- 经营性应交税费；
- 退款负债和经营性预计负债；
- 其他应付款、长期应付款中的经营性部分。

### 基础公式

`经营性应付项目增加＝期末经营性应付余额－期初经营性应付余额－非经营性净增加修正`

### 排除或修正

1. 购买长期资产形成的应付；
2. 借款、债券、融资利息、应付股利和租赁负债；
3. 具有融资实质的供应链融资；
4. 资本化进入长期资产的职工薪酬；
5. 企业合并、处置子公司、非现金结算和境外经营报表折算；
6. 政府补助相关递延收益和应收补助，统一转第16项专门桥接。

### 外币和业务实质

- 经营性应付的本位币汇兑变化一般保留。
- 境外经营报表折算差额排除。
- 将普通应付账款重分类为供应链融资时，应根据融资实质从经营性应付池转出，不以报表科目名称为唯一依据。

## 16. 其他明确调整

本项执行严格白名单，但不是简单要求“事项必须完全没有经营活动现金”。政府补助等同时包含现金和损益影响的事项，必须进行事件桥接。

### 16.1 权益结算股份支付

1. 只加回实际进入当期净利润的权益结算股份支付费用。
2. 进入尚未出售存货的股份支付成本由第13项处理。
3. 资本化进入非经营性长期资产的金额当期不调整。
4. 现金结算股份支付通过经营性负债和实际现金支付处理，不进入本项。

### 16.2 政府补助

政府补助使用独立事件桥接，并将政府补助应收款和递延收益从普通经营性应收、应付池中排除。

统一公式：

`政府补助调节额＝当期实际收到并列入经营活动的政府补助现金－当期政府补助对净利润的净影响`

政府补助退回作为现金流出和损益影响的反向事项处理。

示例：

| 事项 | 经营现金 | 净利润影响 | 调节额 |
|---|---:|---:|---:|
| 收到100并直接确认收益100 | 100 | 100 | 0 |
| 收到100、当期递延收益摊销20 | 100 | 20 | 80 |
| 非现金资产补助当期确认收益20 | 0 | 20 | -20 |
| 确认应收补助收益100但未收款 | 0 | 100 | -100 |
| 本期收到以前确认的应收补助100 | 100 | 0 | 100 |

上述公式同时处理总额法、净额法、递延收益摊销、应收补助和非货币性补助，不再只抓“递延收益摊销”。

### 16.3 债务重组

债务重组不得整项机械加回或扣除。

1. 先识别原债权债务属于经营、投资还是融资性质；
2. 再识别清偿对价是现金、存货、长期资产、金融资产还是权益工具；
3. 已由第6项、第8项、第10项、第13项、第14项或第15项抵销的金额不得重复进入本项；
4. 只有影响净利润、且尚未被其他项目或经营性余额变动抵销的剩余部分，才进入本项；
5. 涉及股东身份或同一控制关系、实质属于权益性投入或分配的，不得按普通债务重组损益处理。

### 16.4 禁止事项

1. 不接收无法解释的倒轧差额；
2. 不按随机比例分配到经营性应收、应付或其他项目；
3. 不因“不确定”就把金额留空；
4. 不重复接收已经由其他项目占用的金额。

## 五、统一防重复规则

### 5.1 金额占用

每个候选金额片段至少记录：

- 来源文件和工作表；
- 原始行号；
- 凭证唯一标识；
- 会计期间；
- 科目全路径；
- 辅助项目及其所属维度；
- 借方金额、贷方金额；
- 对方一级科目；
- 匹配类型；
- 业务事件标识；
- 已归入项目；
- 已占用金额；
- 剩余金额；
- 处理结论；
- 判断依据；
- 是否属于允许的配套抵销。

处理后必须满足：

`原始金额＝已占用金额＋剩余金额`

最终正式结果中，剩余未分类金额必须为零。

### 5.2 项目互斥

1. 第1项与第2项按适用减值模型和项目既定列报口径互斥。
2. 第6项、第7项、第8项和第10项按“业务事件＋资产类型＋损益性质”互斥。
3. 第9项和第10项以实际进入净利润的损益科目及业务性质确定唯一归属。
4. 第11项和第12项分别处理递延所得税资产和负债，不与原减值、折旧或公允价值项目合并。
5. 第16项只处理白名单事件中尚未被前述项目抵销的金额。

### 5.3 允许的配套抵销

以下情况不是重复：

- 折旧、摊销进入存货成本：第3至第5项加回，同时第13项通过存货增加扣除；
- 原事项损益与其递延所得税影响：原事项进入所属项目，递延所得税进入第11或第12项；
- 政府补助现金与补助损益：第16项按事件桥接后的净额调整。

### 5.4 核销修正

1. 存货跌价准备核销原值：不进入第1项计提额，作为第13项修正。
2. 坏账准备核销应收原值：不进入第2项计提额，作为第14项修正。
3. 直接计入损益的存货或应收核销：如果相关损失已经进入第1或第2项，相应原值减少必须在第13或第14项剔除。

## 六、AI判断与人工升级

### 6.1 基本原则

1. 确定性脚本先完成标准化、候选筛选、金额切分、规则命中和勾稽校验。
2. 不能由确定性规则唯一分类的金额片段，必须由AI继续判断。
3. AI必须给出最终建议，不得只输出“待判断”“建议人工确认”。
4. 最终正式结果中的待分类金额必须为零。

### 6.2 AI必须输出的内容

- 最终建议项目；
- 建议金额和符号；
- 结论；
- 建议理由；
- 支持证据；
- 相反证据；
- 适用准则或规则；
- 未采用其他分类的理由；
- 置信度；
- 对16项、经营活动现金净流量和最终勾稽的影响；
- 是否建议升级人工；
- 升级人工的具体冲突点。

### 6.3 人工升级门槛

只有同时满足以下两个条件，才升级人工：

1. 金额绝对值达到或超过实际执行重要性水平；
2. 存在足以改变项目归属或金额的强冲突证据。

即使升级人工，也必须先给出AI首选结论、备选结论、建议理由和两种方案的金额影响。不能把判断责任空白转交人工。

### 6.4 确定性兜底

未达到人工升级门槛但证据仍不完全一致时，按照以下固定顺序落数：

1. 明确准则适用范围；
2. 明确业务事件和资产、负债性质；
3. 完整凭证金额关系；
4. 对方一级科目；
5. 辅助核算；
6. 摘要；
7. 科目余额表及报表勾稽。

AI依据上述证据选择最可能结论，并记录低置信度及相反证据。不得随机分配，也不得把差额随意塞入“其他明确调整”。

## 七、余额表与总体验证

### 7.1 序时账完整性

按末级科目核对：

`序时账借方合计＝余额表本期借方发生额`

`序时账贷方合计＝余额表本期贷方发生额`

差异必须定位到漏行、重复、期间、币种、科目映射或余额表口径，不得直接倒轧进16项。

### 7.2 资产负债表桥接
